# 扫雷（saolei）

C 语言控制台版扫雷，9×9 棋盘，默认 10 颗雷。

## 文件说明

| 文件 | 作用 |
|---|---|
| `test.c` | 程序入口：菜单、游戏流程控制 |
| `game.c` | 棋盘初始化、布雷、排雷、胜负判断 |
| `game.h` | 常量与函数声明 |

## 玩法

1. 运行程序，输入 `1` 开始游戏
2. 输入 `行 列`（从 1 开始，例如 `3 5`）翻开格子
3. 翻到雷即失败；翻开全部 71 个安全格即胜利
4. 主菜单输入 `0` 退出

## 编译运行

```bash
gcc game.c test.c -o saolei
./saolei
```
